# VULPA · Earth System Trend Detective

NASA Space Apps Challenge 2026 — *Be An Earth System Trend Detective*

Live site: https://vvulpa.streamlit.app

VULPA tests whether a change in Earth's climate is real. It runs a seasonal Mann-Kendall test, the Sen slope with a
95% confidence interval and an autocorrelation-corrected t-test on NASA data for 104 regions or any coordinate, and
shows the result on a 3D globe.
